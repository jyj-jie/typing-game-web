# 南湾沙塘布学校科技节班级打字比赛网页系统

这是一个基于 `Node.js + Express + Socket.IO` 开发的局域网实时打字比赛系统，适用于学校科技节、班级竞赛和投影大屏展示场景。

## 功能概览

- 参赛端：学生选择班级、输入姓名后进入等待区，裁判开始比赛后自动切换到比赛页面。
- 比赛页：支持逐字符高亮、实时速度、准确率、进度条、隐藏输入捕获、错误抖动提示。
- 防作弊：禁止复制、粘贴、剪切、右键菜单；检测失焦切屏并记录警告；超过 3 次取消成绩。
- 管理端：裁判登录后可选择文章、设置时长、开始、暂停、继续、提前结束比赛。
- 大屏页：实时展示班级总分柱状图与个人速度榜 Top10。
- 成绩导出：支持将班级总分和个人成绩导出为 CSV 文件。

## 安装依赖

请先确保本机已安装 Node.js 18 或更高版本，然后在项目根目录执行：

```bash
npm install
```

## 启动方式

开发模式：

```bash
npm run dev
```

正式启动：

```bash
npm start
```

默认端口为 `3000`，启动后可访问：

- 参赛端：`http://localhost:3000/player.html`
- 管理端：`http://localhost:3000/admin.html`
- 大屏页：`http://localhost:3000/screen.html`

## 局域网访问方式

1. 在运行服务的电脑上执行 `ipconfig`，找到当前局域网 IPv4 地址，例如 `192.168.1.20`。
2. 确保该电脑与学生端设备在同一局域网内。
3. 若系统防火墙提示是否允许访问，请允许 Node.js 的局域网通信。
4. 其他设备通过以下地址访问：

```text
http://192.168.1.20:3000/player.html
http://192.168.1.20:3000/admin.html
http://192.168.1.20:3000/screen.html
```

## 默认配置说明

- 管理密码：`admin123`
- 默认比赛时长：`300` 秒
- 心跳间隔：`2` 秒
- 掉线判定：`5` 秒未收到心跳则标记离线
- 文章数量：内置 `3` 篇科技主题中英文混合短文

如需修改，可直接编辑 `server.js` 中的以下内容：

- `ADMIN_PASSWORD`
- `DEFAULT_DURATION`
- `HEARTBEAT_INTERVAL`
- `DISCONNECT_THRESHOLD`
- `classList`
- `articles`

## 计分规则实现说明

- 速度：`正确字符数 ÷ 用时(分钟)`
- 准确率：`(总击键数 - 错误击键数) ÷ 总击键数 × 100%`
- 个人得分：`速度 × 准确率小数值`
- 退格次数超过 `5` 次：额外扣 `2` 分
- 失焦超过 `3` 次：成绩取消，记为违规
- 班级总分：该班所有有效选手个人得分之和

## 使用流程建议

1. 裁判先打开管理端，确认文章与比赛时长设置。
2. 学生在各自设备打开参赛端，选择班级并输入姓名登录。
3. 确认每个班级已有 `3-5` 名选手在线后，裁判点击“开始比赛”。
4. 比赛过程中可在管理端查看实时状态，也可打开大屏页投影展示。
5. 比赛结束后，在管理端点击“导出 CSV”保存成绩。

## 注意事项

- 同一班级下同名选手不能重复登录。
- 比赛开始后不允许新增选手加入。
- 参赛端以服务端计时和成绩为准，客户端只负责展示与上报实时数据。
- 如果需要长期保存历史成绩，可将 `storage/results.json` 接入更多归档逻辑。
