# 南湾沙塘布学校科技节班级打字比赛网页系统

基于 `Node.js + Express + Socket.IO` 开发的局域网实时打字比赛系统，适用于学校科技节、班级竞赛和投影大屏展示场景。

## 功能概览

- **参赛端**：学生选择班级、输入姓名后进入等待区，裁判开始比赛后自动切换到比赛页面。
- **比赛页**：支持逐字符高亮、实时速度、平均速度、准确率、进度条、隐藏输入捕获、错误抖动提示。
- **断线恢复**：比赛中意外退出或断网后重连，自动恢复已输入进度和打字记录，无需从头开始。
- **防作弊**：禁止复制、粘贴、剪切、右键菜单；检测失焦切屏并记录警告。
- **管理端**：裁判登录后可选择文章、设置时长、开始、暂停、继续、提前结束比赛；导入 TXT 文章、Excel 学生名单。
- **大屏页**：实时展示班级总分柱状图与个人实时速度榜 Top10。
- **排行榜双速指标**：显示30秒滑动窗口实时速度 + 累计平均速度，排名每秒随选手表现动态变化。
- **成绩导出**：支持将班级总分和个人成绩导出为 CSV 文件。
- **强制换绑**：选手断线重连时，可强制挤掉旧连接并在此设备重新登录。
- **优雅关闭**：Ctrl+C 或进程管理器停止时自动保存比赛成绩。
- **Checkpoint**：比赛进行中每 10 秒自动保存进度快照，崩溃后可恢复。
- **健康检查**：`/api/health` 端点供监控工具检测服务状态。

## 安装依赖

请先确保本机已安装 Node.js 18 或更高版本，然后在项目根目录执行：

```bash
npm install
```

## 启动方式

Windows 一键启动（双击运行或命令行）：

```bash
start.bat
```

或直接使用 Node.js：

```bash
npm start
```

默认端口为 `3000`，可通过环境变量 `PORT` 自定义。启动后可访问：

| 角色 | 地址 |
|------|------|
| 参赛端 | `http://localhost:3000/player.html` |
| 管理端 | `http://localhost:3000/admin.html` |
| 大屏页 | `http://localhost:3000/screen.html` |
| 健康检查 | `http://localhost:3000/api/health` |

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 服务端口 | `3000` |
| `ADMIN_PASSWORD` | 管理端登录密码 | `admin123` |
| `CORS_ORIGIN` | CORS 允许来源（逗号分隔多个域名） | 局域网网段自动匹配 |
| `DISCONNECT_THRESHOLD` | 掉线判定阈值（毫秒） | `5000` |
| `CHECKPOINT_INTERVAL` | 进度快照保存间隔（毫秒） | `10000` |
| `MAX_BODY_SIZE` | 请求体最大大小 | `1mb` |
| `TRUST_PROXY` | 是否信任反向代理的 X-Forwarded-For 头 | `false` |

### 生产部署建议

推荐使用 **PM2** 进程管理器进行生产部署：

```bash
npm install -g pm2
pm2 start server.js --name typing-game
pm2 save
pm2 startup
```

也可使用 **Docker** 部署（自行编写 Dockerfile）。

> ⚠️ 本项目**不适合部署到 Vercel / Netlify 等 Serverless 平台**，因为 Socket.IO 需要长连接 WebSocket 支持，Serverless 函数有执行时间限制。

## 局域网访问方式

1. 在运行服务的电脑上执行 `ipconfig`，找到当前局域网 IPv4 地址，例如 `192.168.1.20`。
2. 确保该电脑与学生端设备在同一局域网内。
3. 若系统防火墙提示是否允许访问，请允许 Node.js 的局域网通信。
4. 其他设备通过以下地址访问：

```text
http://192.168.1.20:3000/player.html
http://192.168.1.20:3000/admin.html
http://192.168.1.20:3000/screen.html
```

## 配置说明

### 内置文章

系统内置 3 篇中文比赛文章，可通过管理端 TXT 导入更多文章。导入的文章持久化至 `storage/articles.json`，服务重启后自动恢复。

### 学生名单

通过管理端导入 Excel 文件（仅需包含"班级"和"学生姓名"两列）来设置参赛学生名单。名单持久化至 `storage/student-roster.json`。

导入学生名单后，班级列表会自动从名单中提取。未导入名单时，系统默认提供 1年级1班 ~ 6年级6班 共 36 个预设班级。

### 可调参数（server.js 内）

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `DEFAULT_DURATION` | 默认比赛时长（秒） | `300` |
| `HEARTBEAT_INTERVAL` | 心跳间隔（毫秒） | `2000` |
| `SPEED_HISTORY_WINDOW_MS` | 速度历史保留窗口 | `60000` |
| `RECENT_SPEED_WINDOW_MS` | 实时速度计算窗口 | `30000` |

大多数参数已支持通过环境变量覆盖（见上方环境变量表）。

## 计分规则

- **平均速度**：`总正确字数 ÷ 总耗时（分钟）`
- **实时速度**：`最近30秒窗口内的正确字数增量 ÷ 时间增量（分钟）`，排行榜按此排序
- **准确率**：`（总击键数 − 错误击键数）÷ 总击键数 × 100%`
- **个人得分**：`完成度分(60%) + 速度分(50%) + 准确率分(40%)`，满分 150 分
- **班级总分**：该班所有有效选手个人得分之和

## 使用流程建议

1. 裁判先打开管理端（`/admin.html`），登录后确认文章与比赛时长设置。
2. 在管理端导入学生名单（Excel），确认班级和选手信息已正确加载。
3. （可选）导入更多比赛文章（TXT 格式，UTF-8 编码）。
4. 学生在各自设备打开参赛端（`/player.html`），选择班级并点击自己姓名登录。
5. 确认选手已在线后，裁判点击"开始比赛"。
6. 比赛过程中可在管理端查看实时状态，也可打开大屏页（`/screen.html`）投影展示。
7. 比赛结束后，在管理端点击"导出 CSV"保存成绩。

## 故障恢复

| 场景 | 系统行为 |
|------|----------|
| 选手比赛中断网 | 服务端保留所有打字进度；客户端自动重连后恢复输入状态 |
| 服务端正常关闭（Ctrl+C） | 自动保存比赛结果后安全退出 |
| 服务端意外崩溃 | `race-checkpoint.json` 中保留最近一次自动保存的快照 |
| 端口被占用 | 输出友好提示并退出，可设 `PORT` 环境变量换端口 |
| 磁盘满无法落盘 | 打印错误日志，不影响比赛正常进行 |

## 注意事项

- 同一班级下同名选手不能重复登录；若需更换设备，可选择"强制换绑"挤掉旧连接。
- 比赛开始后不允许新增选手加入。
- 服务端是唯一计时与成绩权威，客户端只负责展示与上报实时数据。
- 导入的文章和名单都会持久化，服务重启后自动恢复，无需重复导入。
- 如需更换机器部署，将 `storage/` 目录一并复制即可保留所有数据。
- 建议生产环境通过环境变量设置 `ADMIN_PASSWORD`，不要使用默认密码。
